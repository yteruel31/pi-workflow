# v0.1.0 validation evidence

This record separates observed package evidence from model-dependent workflow behavior. It does not claim that prompt instructions were enforced at runtime.

## Observed package validation

- Pi version: `0.80.10`.
- `npm test` passed all 22 dependency-free contract tests.
- `npm pack --dry-run` passed and reported the intended ten package files.
- The public repository is reachable at `https://github.com/yteruel31/pi-workflow` with default branch `main`.
- Installation from `git:github.com/yteruel31/pi-workflow` succeeded.
- `pi update git:github.com/yteruel31/pi-workflow` updated the installed checkout successfully.
- Source, remote `main`, and installed checkout all resolved to commit `4ecb1978f9a663ec53b3c4f6ffc8935e342c306b` after the final review-fix batch.
- The installed package contained exactly the four skill files for `yt-brainstorm`, `yt-plan`, `yt-work`, and `yt-review`.
- Contract tests cover package discovery, valid skill frontmatter, optional artifacts, bounded delegation, sequential worker commits, contradictory directives, adaptive report-only review, and documented trust boundaries.

## Model-dependent validation gaps

The following scenarios require live model behavior and were not executed as deterministic release tests:

- Direct live invocation of all four skills.
- Worker behavior across sequential units, foreign-change isolation, failed-unit stopping, parent-owned commits, and missing-role fallback.
- One/two/three-reviewer routing, reviewer compliance with report-only instructions, observable local-state comparison, remote-evidence reporting, and missing-role fallback.

These remain residual validation risks rather than claims proven by the static suite.
